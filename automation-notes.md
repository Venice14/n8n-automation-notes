# My n8n Automation Practice

## Workflows I built

1. Gmail to Google Sheets
2. Scheduled task reminder
3. Google Form lead notification
4. Webhook lead receiver
5. Service router using Switch
6. Error alert email
7. CRM follow-up alert
8. API and JSON contact practice

## Things I learned

- A trigger starts a workflow.
- A node does one job.
- A filter decides what can continue.
- A switch sends information to different paths.
- A webhook receives information from another app.
- JSON is information arranged in fields.
- GitHub saves my project files and their changes.

## Safety rule

Never put passwords, API keys, personal customer data, or secret header values in GitHub.
